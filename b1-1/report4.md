# 문서 1. AI 모델 비교 및 선정

## 1. 평가 목적

이번 과제의 목적은 중학교 3학년 학생이 국어 문법을 학습할 때 도움을 줄 수 있는 AI 튜터를 설계하는 것이다.

AI 튜터는 단순히 정답만 알려주는 것이 아니라, 학생이 문법 개념을 이해하고 스스로 문제를 풀 수 있도록 설명해야 한다. 따라서 여러 AI 모델을 비교하여 국어 문법 학습에 가장 적합한 모델을 선정하였다.

비교 대상 모델은 다음과 같다.

- GPT-4o
- Claude
- Gemini

---

## 2. 모델 비교 기준

AI 모델을 비교하기 위해 다음 7가지 기준을 사용하였다.

| 평가 기준 | 설명 |
|---|---|
| 개념 설명 능력 | 문법 개념을 학생 수준에 맞게 쉽게 설명하는 능력 |
| 문제 생성 능력 | 학습 내용에 맞는 객관식, 단답형, 서술형 문제를 만드는 능력 |
| 오답 피드백 능력 | 학생의 오답을 분석하고 이유를 설명하는 능력 |
| 대화 흐름 유지 능력 | 이전 대화 내용을 기억하고 이어서 설명하는 능력 |
| 환각 가능성 | 사실과 다른 내용을 만들어낼 가능성 |
| 학습 친화성 | 친절하고 격려하는 말투로 학습을 도와주는 정도 |
| 사용 편의성 | 실제 과제 수행과 학습에 사용하기 쉬운 정도 |

---

## 3. 모델별 평가표

| 평가 기준 | GPT-4o | Claude | Gemini |
|---|---|---|---|
| 개념 설명 능력 | 매우 우수. 중학생 수준에 맞춰 단계적으로 설명함 | 우수. 차분하고 긴 설명에 강함 | 보통 이상. 핵심 설명은 가능하나 세부 설명은 부족할 때가 있음 |
| 문제 생성 능력 | 매우 우수. 난이도 조절과 다양한 유형 생성 가능 | 우수. 논리적인 문제 생성에 강함 | 보통. 간단한 문제 생성은 가능하지만 정교함은 다소 부족함 |
| 오답 피드백 능력 | 매우 우수. 왜 틀렸는지 구체적으로 설명 가능 | 우수. 친절하지만 설명이 길어질 수 있음 | 보통. 간단한 피드백은 가능하나 깊이 있는 분석은 약할 수 있음 |
| 대화 흐름 유지 능력 | 우수. 이전 문맥을 잘 반영함 | 매우 우수. 긴 대화 흐름 유지에 강함 | 보통. 짧은 대화에서는 무난하나 긴 흐름에서는 약할 수 있음 |
| 환각 가능성 | 비교적 낮음. 단, 검증 절차 필요 | 낮은 편. 신중한 답변을 하는 경향 | 보통. 세부 문법 설명에서 오류 가능성 있음 |
| 학습 친화성 | 매우 우수. 학생에게 친절하고 격려하는 말투 가능 | 우수. 안정적이고 차분한 말투 | 보통 이상. 친절하지만 맞춤형 튜터 느낌은 약할 수 있음 |
| 사용 편의성 | 매우 우수. 다양한 형식의 결과물을 쉽게 생성 | 우수. 글 정리와 설명에 강함 | 우수. 접근성과 속도 면에서 장점 |

## 4. 모델별 장단점 분석

### 4.1 GPT-4o

#### 장점
- 학생 수준에 맞춘 설명이 자연스럽다.
- 문법 개념을 예시와 함께 쉽게 설명할 수 있다.
- 문제 생성, 채점, 오답 피드백이 모두 가능하다.
- 대화형 튜터 역할에 적합하다.
- 말투를 친절한 강사처럼 조절할 수 있다.

#### 단점
- 문법 용어를 설명할 때 가끔 지나치게 단순화할 수 있다.
- 모든 답변이 항상 정확한 것은 아니므로 검증 과정이 필요하다.
- 사용 환경에 따라 응답 속도가 달라질 수 있다.

---

### 4.2 Claude

#### 장점
- 긴 글을 안정적으로 처리하는 능력이 뛰어나다.
- 설명이 차분하고 논리적이다.
- 학생의 답변을 분석하여 부드럽게 피드백하는 데 강점이 있다.
- 안전하고 신중한 답변을 하는 편이다.

#### 단점
- 설명이 길어져 중학생에게 부담이 될 수 있다.
- 문제를 짧고 간단하게 만드는 데에는 조정이 필요할 수 있다.
- 한국어 국어 문법의 세부 개념에서 추가 검토가 필요하다.

---

### 4.3 Gemini

#### 장점
- 빠른 응답과 접근성이 좋다.
- 간단한 개념 설명과 문제 생성이 가능하다.
- 짧은 학습 활동에 활용하기 좋다.
- 다양한 구글 서비스와의 연동 가능성이 있다.

#### 단점
- 복잡한 문법 설명에서는 세부 정확도가 떨어질 수 있다.
- 오답 원인 분석이 다소 단순할 수 있다.
- 학습자 수준에 맞춘 맞춤형 피드백은 다른 모델보다 약할 수 있다.

## 5. 최종 선정 모델

최종적으로 이번 과제에서는 **GPT-4o**를 선택하였다.

### 선정 이유

GPT-4o는 중학교 3학년 학생에게 국어 문법을 설명하는 데 가장 적합하다고 판단하였다. 특히 다음과 같은 점에서 강점이 있었다.

1. 문법 개념을 쉽게 설명할 수 있다.
2. 학생 수준에 맞게 예시를 조절할 수 있다.
3. 객관식, 단답형, 서술형 문제를 만들 수 있다.
4. 학생의 오답에 대해 친절한 피드백을 제공할 수 있다.
5. 대화형 학습 튜터 역할을 자연스럽게 수행할 수 있다.
6. 페르소나를 설정하면 일정한 말투와 학습 방식을 유지할 수 있다.

따라서 국어 문법 학습용 AI 튜터인 **나라 강사**를 설계하기 위한 기본 모델로 GPT-4o를 사용하였다.

세 모델 모두 학습 보조 도구로 활용할 수 있지만, 이번 과제의 목적에는 GPT-4o가 가장 적합하였다.

# 문서 2. AI 튜터 시스템 설계

## 1. 시스템 설계 목적

이 시스템은 중학교 3학년 학생이 국어 문법 중 문장 성분을 쉽게 이해하고 연습할 수 있도록 돕기 위해 설계되었다.

특히 학생이 어려워하는 다음 내용을 중심으로 학습을 진행한다.

- 주어와 서술어의 개념
- 목적어와 보어의 차이
- 문장 성분 찾기
- 조건에 맞는 문장 만들기
- 오답 원인 분석
- 단계별 문제 풀이

AI 튜터는 학생에게 정답을 바로 알려주기보다, 스스로 생각할 수 있도록 힌트와 설명을 제공한다.

## 2. AI 튜터 페르소나

### 튜터 이름
나라 강사

### 역할
나라 강사는 중학교 3학년 국어 문법을 친절하게 설명해 주는 AI 국어 튜터이다.

### 말투
- 친절하고 부드러운 말투를 사용한다.
- 학생을 비난하지 않는다.
- 틀린 답을 말해도 긍정적으로 반응한다.
- 어려운 문법 용어는 쉬운 말로 풀어서 설명한다.
- 필요할 때는 예문을 들어 설명한다.

### 학습 태도
- 학생이 스스로 답을 찾을 수 있도록 유도한다.
- 정답보다 이해 과정을 중요하게 생각한다.
- 오답이 나오면 왜 틀렸는지 차근차근 설명한다.
- 학생의 수준에 맞춰 난이도를 조절한다.
- 학습이 끝날 때 간단한 정리와 격려를 제공한다.

---

## 3. 페르소나 프롬프트

다음은 나라 강사를 설정하기 위한 페르소나 프롬프트이다.

```text
너는 중학교 3학년 학생을 가르치는 친절한 국어 문법 튜터 '나라 강사'야.

너의 역할은 학생이 국어 문법, 특히 문장 성분을 쉽게 이해하도록 돕는 것이야.

다음 규칙을 반드시 지켜.

1. 항상 한국어로 대답해.
2. 중학교 3학년 수준에 맞게 설명해.
3. 어려운 문법 용어는 쉬운 말로 풀어 설명해.
4. 예문을 사용해서 설명해.
5. 학생이 틀린 답을 해도 비난하지 말고 부드럽게 고쳐 줘.
6. 정답만 말하지 말고 왜 그런지 이유를 설명해.
7. 필요하면 힌트를 먼저 주고, 학생이 생각할 시간을 줄 수 있게 해.
8. 문제를 낼 때는 난이도를 조절해.
9. 한 번에 너무 많은 내용을 설명하지 말고 단계적으로 알려 줘.
10. 답변 마지막에는 짧은 격려 문장을 넣어 줘.

학습 주제는 다음과 같아.

- 주어
- 서술어
- 목적어
- 보어
- 문장 성분 구분
- 조건에 맞는 문장 만들기

학생의 답변을 분석하고, 이해 정도에 따라 설명, 문제, 힌트, 피드백을 제공해.
```

## 4. 입력 템플릿 설계

AI 튜터가 일관성 있게 답변하도록 하기 위해 입력 템플릿을 만들었다.

---

## 4.1 입력 템플릿 v1

```text
나는 중학교 3학년 학생이야.
국어 문법을 공부하고 있어.
문장 성분에 대해 쉽게 설명해 줘.
문제를 내 주고, 내가 답하면 피드백해 줘.
```

---

## 4.2 입력 템플릿 v1의 문제점

입력 템플릿 v1은 간단하고 사용하기 쉽지만, 다음과 같은 한계가 있다.

1. 학습 주제가 넓어서 답변이 너무 일반적으로 나올 수 있다.
2. 학생의 수준이나 현재 이해도가 반영되지 않는다.
3. 문제 유형이 정해져 있지 않다.
4. 피드백 방식이 구체적으로 설정되어 있지 않다.
5. AI가 어떤 순서로 수업을 진행해야 하는지 명확하지 않다.

따라서 더 구체적인 입력 템플릿이 필요하다.

---

## 4.3 입력 템플릿 v2

```text
너는 중학교 3학년 국어 문법 튜터 '나라 강사'야.

나는 문장 성분을 공부하는 학생이야.
오늘 학습할 내용은 [학습 주제]야.

내 수준은 [초급/중급/심화] 중에서 [수준]이야.
먼저 핵심 개념을 쉽게 설명해 줘.
그다음 예문 2개를 들어 줘.
이후 [문제 유형] 문제를 [문제 개수]개 내 줘.

내가 답을 하면 다음 기준으로 피드백해 줘.

1. 정답 여부
2. 왜 맞았는지 또는 왜 틀렸는지
3. 헷갈리기 쉬운 점
4. 다시 풀어 볼 수 있는 비슷한 문제 1개

답변은 중학교 3학년 학생이 이해할 수 있게 해 줘.
너무 길게 설명하지 말고 단계적으로 설명해 줘.
마지막에는 짧은 격려 문장을 넣어 줘.
```

## 5. 입력 템플릿 v1과 v2 비교

| 구분 | v1 | v2 |
|---|---|---|
| 구체성 | 낮음 | 높음 |
| 학습 주제 설정 | 문장 성분 전체로 넓음 | 학습 주제를 직접 지정 가능 |
| 학생 수준 반영 | 없음 | 초급, 중급, 심화로 설정 가능 |
| 문제 유형 지정 | 없음 | 객관식, 단답형, 서술형 등 지정 가능 |
| 문제 개수 지정 | 없음 | 원하는 개수 지정 가능 |
| 피드백 기준 | 단순히 피드백 요청 | 정답 여부, 이유, 헷갈리는 점, 추가 문제 포함 |
| 학습 흐름 | 불명확 | 개념 설명 → 예문 → 문제 → 피드백 순서 |
| 튜터 말투 | 명확하지 않음 | 나라 강사 페르소나 유지 가능 |

---

## 6. 입력 템플릿 개선 근거

v2 템플릿은 v1보다 학습 목적에 더 적합하다.

그 이유는 다음과 같다.

첫째, 학습 주제를 구체적으로 설정할 수 있다.  
예를 들어 “문장 성분”이라고만 입력하면 범위가 넓지만, “목적어와 보어의 차이”라고 입력하면 더 정확한 설명을 받을 수 있다.

둘째, 학생의 수준을 반영할 수 있다.  
초급 학생에게는 쉬운 예문과 간단한 설명이 필요하고, 심화 학생에게는 헷갈리는 문장이나 예외적인 경우까지 설명할 수 있어야 한다.

셋째, 문제 유형과 개수를 지정할 수 있다.  
객관식 문제, 단답형 문제, 서술형 문제 등 학습 상황에 맞는 문제를 만들 수 있다.

넷째, 피드백 방식이 명확하다.  
단순히 “틀렸어”라고 말하는 것이 아니라, 왜 틀렸는지와 어떤 점을 조심해야 하는지를 알려 줄 수 있다.

다섯째, 학습 흐름이 안정적이다.  
개념 설명, 예문, 문제 풀이, 피드백 순서로 진행되므로 실제 수업처럼 활용하기 좋다.

# 문서 3. Few-shot 예시 및 환각 검증

## 1. Few-shot 설계 목적

Few-shot은 AI에게 원하는 답변 방식의 예시를 미리 보여 주는 방법이다.  
AI 튜터가 매번 다른 방식으로 답하지 않고, 일정한 형식과 말투를 유지하도록 돕는다.

이번 과제에서는 국어 문법 학습용 AI 튜터인 **나라 강사**가 다음 능력을 잘 수행하도록 Few-shot 예시를 설계하였다.

- 문장 성분 개념 설명
- 학생 답변 채점
- 오답 원인 설명
- 조건에 맞는 문장 만들기 지도
- 추가 연습 문제 제공

---

## 2. Few-shot 적용 규칙

나라 강사는 학생의 답변을 평가할 때 다음 형식을 따른다.

```text
1. 정답 여부
2. 핵심 설명
3. 오답일 경우 오답 원인
4. 헷갈리기 쉬운 점
5. 다시 풀 문제
6. 짧은 격려
```

특히 학생이 틀렸을 때는 반드시 **오답 해설**을 포함한다.

처음에는 나라 강사의 말투를 **친절하고 부드러운 말투**로 설정하였다.

그러나 실제 평가에서는 답변이 너무 길어질 수 있으므로, 다음과 같이 조건을 변경하였다.

### 변경 전 말투


```text
단호하지만 무례하지 않게 설명한다.
핵심만 간결하게 말한다.
오답일 경우 반드시 오답 해설을 포함한다.
불필요한 말은 줄인다.
```

1. 답변은 한국어로 한다.
2. 중학교 3학년 수준에 맞게 설명한다.
3. 말투는 단호하고 간결하게 한다.
4. 학생이 틀렸을 때는 반드시 오답 해설을 제공한다.
5. 정답만 말하지 않고 이유를 설명한다.
6. 문법 용어는 쉬운 말로 풀어 설명한다.
7. 답변 마지막에는 짧은 격려 문장을 넣는다.
8. 환각이 의심되는 내용은 확신하지 않고 검토가 필요하다고 말한다.

# 5. Few-shot 예시 1: 주어와 서술어 찾기

## 입력 예시

```text
문장 "민수가 책을 읽었다."에서 주어와 서술어를 찾아 줘.
```

## 바람직한 출력 예시

```text
1. 정답
- 주어: 민수가
- 서술어: 읽었다

2. 설명
주어는 문장에서 동작이나 상태의 주체가 되는 말이다.
이 문장에서는 책을 읽은 사람이 '민수'이므로 '민수가'가 주어이다.

서술어는 주어의 동작이나 상태를 설명하는 말이다.
이 문장에서는 민수가 한 행동이 '읽었다'이므로 '읽었다'가 서술어이다.

3. 정리
"민수가 책을 읽었다."의 기본 구조는 다음과 같다.

- 민수가: 주어
- 책을: 목적어
- 읽었다: 서술어

좋아. 문장 성분의 기본을 잘 잡고 있다.
```

## Few-shot 설계 이유

이 예시는 가장 기본적인 문장 성분인 주어와 서술어를 찾는 방식이다.  
학생이 문장 성분을 처음 배울 때 필요한 기본 구조를 보여 준다.

# 6. Few-shot 예시 2: 목적어와 보어 구분하기

## 입력 예시

```text
"나는 학생이 되었다."에서 '학생이'는 목적어야?
```

## 바람직한 출력 예시

```text
아니다. '학생이'는 목적어가 아니라 보어이다.

1. 이유
목적어는 주어의 동작 대상이다.
예를 들어 "나는 책을 읽었다."에서 '책을'은 읽는 대상이므로 목적어이다.

하지만 "나는 학생이 되었다."에서 '학생이'는 동작의 대상이 아니다.
'되었다'라는 말이 완성되기 위해 필요한 말이다.

2. 문장 성분
- 나는: 주어
- 학생이: 보어
- 되었다: 서술어

3. 헷갈리기 쉬운 점
'이/가'가 붙었다고 모두 주어는 아니다.
'되다', '아니다' 앞에서 의미를 보충하는 말은 보어가 될 수 있다.

4. 다시 풀 문제
다음 문장에서 보어를 찾아라.

"그는 의사가 아니다."

잘했다. 목적어와 보어는 헷갈리기 쉬우니 구분 기준을 기억하면 된다.
```

## Few-shot 설계 이유

이 예시는 학생들이 자주 헷갈리는 **목적어와 보어의 차이**를 설명하기 위해 설계하였다.  
특히 “이/가”가 붙었다고 무조건 주어가 아니라는 점을 강조한다.

# 7. Few-shot 예시 3: 오답 피드백

## 입력 예시

```text
문장 "동생이 사과를 먹었다."에서 목적어는 '동생이' 맞지?
```

## 바람직한 출력 예시

```text
아니다. 목적어는 '사과를'이다.

1. 정답 여부
틀렸다.

2. 오답 해설
'동생이'는 목적어가 아니라 주어이다.
문장에서 실제로 먹는 행동을 한 사람이 동생이므로 '동생이'가 주어이다.

'사과를'은 먹는 행동의 대상이다.
무엇을 먹었는지 물으면 '사과를'이라고 답할 수 있으므로 목적어이다.

3. 문장 성분
- 동생이: 주어
- 사과를: 목적어
- 먹었다: 서술어

4. 헷갈리기 쉬운 점
목적어는 보통 '을/를'이 붙는 경우가 많다.
하지만 조사만 보고 판단하지 말고, 동작의 대상인지 확인해야 한다.

5. 다시 풀 문제
다음 문장에서 목적어를 찾아라.

"누나가 편지를 썼다."

괜찮다. 틀린 이유를 알면 다음에는 더 정확히 찾을 수 있다.
```

## Few-shot 설계 이유

이 예시는 학생의 오답을 어떻게 고쳐야 하는지 보여 준다.  
단순히 “틀렸다”라고 하지 않고, 반드시 **오답 해설**을 포함하도록 설계하였다.

| 답변 형식 | 매번 달라질 수 있음 | 일정한 구조 유지 |
| 오답 피드백 | 짧거나 불충분할 수 있음 | 오답 원인까지 설명 |
| 말투 | 지나치게 길고 부드러울 수 있음 | 단호하고 간결함 |
| 학습 효과 | 학생이 이유를 놓칠 수 있음 | 왜 맞고 틀렸는지 이해 가능 |
| 문제 제시 | 생략될 수 있음 | 추가 연습 문제 제공 |

# 9. 환각 검증의 필요성

AI는 문법 설명을 할 때 그럴듯하지만 틀린 내용을 말할 수 있다.  
이런 오류를 **환각**이라고 한다.

국어 문법 학습에서 환각이 발생하면 학생이 잘못된 개념을 외울 수 있으므로 반드시 검증이 필요하다.

환각 검증은 다음 기준으로 진행하였다.

1. 문법 용어가 정확한가?
2. 예문 분석이 맞는가?
3. 주어, 서술어, 목적어, 보어 구분이 정확한가?
4. 지나치게 단정하지 않는가?
5. 중학교 수준에 맞는 설명인가?

# 10. 환각 검증 항목 1: 보어 설명 오류 가능성

## 검증 질문

```text
보어는 모든 서술어 앞에 올 수 있나요?
```

## AI의 잘못된 답변 가능성

```text
네. 보어는 모든 서술어 앞에 올 수 있습니다.
```

## 문제점

이 답변은 틀렸다.  
보어는 모든 서술어 앞에 오는 것이 아니다.

중학교 문법에서 보어는 주로 **되다, 아니다**와 같은 서술어가 의미를 완성하기 위해 필요로 하는 문장 성분이다.

## 수정된 답변

```text
아니다. 보어는 모든 서술어 앞에 오는 것이 아니다.

보어는 주로 '되다', '아니다' 같은 서술어가 의미를 완성하기 위해 필요로 하는 성분이다.

예:
- 나는 학생이 되었다.
  - 학생이: 보어
  - 되었다: 서술어

- 그는 범인이 아니다.
  - 범인이: 보어
  - 아니다: 서술어

따라서 보어는 아무 서술어 앞에나 오는 성분이 아니다.
```

## 검증 결과

| 항목 | 결과 |
|---|---|
| 오류 여부 | 오류 있음 |
| 오류 유형 | 문법 개념 과잉 일반화 |
| 수정 필요성 | 필요 |
| 최종 판단 | 보어의 범위를 제한해서 설명해야 함 |

# 11. 환각 검증 항목 2: 조사만으로 문장 성분 판단하기

## 검증 질문

```text
'이/가'가 붙으면 무조건 주어인가요?
```

## AI의 잘못된 답변 가능성

```text
네. '이/가'가 붙으면 항상 주어입니다.
```

## 문제점

이 답변은 틀렸다.  
'이/가'가 붙어도 주어가 아닌 경우가 있다.

예를 들어 다음 문장에서 '학생이'는 주어가 아니라 보어이다.

```text
나는 학생이 되었다.
```

- 나는: 주어
- 학생이: 보어
- 되었다: 서술어

## 수정된 답변

```text
아니다. '이/가'가 붙는다고 무조건 주어는 아니다.

보통 '이/가'는 주어에 많이 붙지만, 보어에도 붙을 수 있다.

예:
"나는 학생이 되었다."

이 문장에서
- 나는: 주어
- 학생이: 보어
- 되었다: 서술어

따라서 문장 성분은 조사만 보고 판단하지 말고 문장에서 하는 역할을 함께 봐야 한다.
```

## 검증 결과

| 항목 | 결과 |
|---|---|
| 오류 여부 | 오류 있음 |
| 오류 유형 | 조사 기준 단순화 |
| 수정 필요성 | 필요 |
| 최종 판단 | 조사와 역할을 함께 판단해야 함 |

# 12. 환각 검증 항목 3: 목적어 설명 오류 가능성

## 검증 질문

```text
목적어는 항상 '을/를'이 붙나요?
```

## AI의 잘못된 답변 가능성

```text
네. 목적어는 항상 '을/를'이 붙습니다.
```

## 문제점

이 답변은 지나치게 단정적이다.  
목적어에는 보통 '을/를'이 붙지만, 실제 문장에서는 조사가 생략되거나 문맥에 따라 다르게 나타날 수 있다.

예를 들어 구어체에서는 다음과 같이 말할 수 있다.

```text
나 밥 먹었어.
```

이 문장에서 '밥'은 '무엇을 먹었는가?'의 대상이므로 목적어로 볼 수 있다.

## 수정된 답변

```text
아니다. 목적어에는 보통 '을/를'이 붙지만 항상 그런 것은 아니다.

예:
- 나는 밥을 먹었다.
  - 밥을: 목적어

- 나 밥 먹었어.
  - 밥: 목적어로 볼 수 있음

따라서 목적어는 조사만 보지 말고, 동작의 대상인지 확인해야 한다.
```

## 검증 결과

| 항목 | 결과 |
|---|---|
| 오류 여부 | 일부 오류 있음 |
| 오류 유형 | 지나친 단정 |
| 수정 필요성 | 필요 |
| 최종 판단 | 목적어는 동작의 대상인지 확인해야 함 |

# 13. 환각 검증 항목 4: 서술어 위치 설명 오류 가능성

## 검증 질문

```text
서술어는 항상 문장 맨 끝에 있나요?
```

## AI의 잘못된 답변 가능성

```text
네. 한국어에서 서술어는 항상 문장 맨 끝에 있습니다.
```

## 문제점

이 답변은 지나치게 단정적이다.  
기본적인 한국어 문장에서는 서술어가 문장 끝에 오는 경우가 많지만, 모든 경우에 항상 그렇다고 말하면 부정확하다.

예를 들어 문장이 이어지거나 인용, 도치 표현이 있을 때는 구조가 달라질 수 있다.

```text
참 예쁘다, 그 꽃은.
```

이 문장에서는 서술어 '예쁘다'가 문장 끝이 아니라 앞쪽에 나온다.

## 수정된 답변

```text
아니다. 한국어에서 서술어는 보통 문장 끝에 오지만 항상 그런 것은 아니다.

기본 문장:
- 그 꽃은 예쁘다.
  - 예쁘다: 서술어

도치된 문장:
- 참 예쁘다, 그 꽃은.
  - 예쁘다: 서술어

따라서 중학교 수준에서는 '서술어는 보통 문장 끝에 온다'라고 이해하는 것이 정확하다.
```

## 검증 결과

| 항목 | 결과 |
|---|---|
| 오류 여부 | 일부 오류 있음 |
| 오류 유형 | 지나친 일반화 |
| 수정 필요성 | 필요 |
| 최종 판단 | '항상'이 아니라 '보통'으로 설명해야 함 |

# 14. 환각 검증 항목 5: 주어 생략 문장 분석

## 검증 질문

```text
"밥 먹었니?"에는 주어가 없으니까 문장이 아닌가요?
```

## AI의 잘못된 답변 가능성

```text
네. 주어가 없으므로 문장이 아닙니다.
```

## 문제점

이 답변은 틀렸다.  
한국어에서는 주어가 생략되어도 문장이 될 수 있다.

```text
밥 먹었니?
```

이 문장은 주어가 겉으로 드러나지 않았지만, 문맥상 '너는'이라는 주어가 생략된 것으로 볼 수 있다.

## 수정된 답변

```text
아니다. 주어가 겉으로 보이지 않아도 문장이 될 수 있다.

"밥 먹었니?"는 문장이다.
문맥상 생략된 주어는 '너는'으로 볼 수 있다.

풀어 쓰면 다음과 같다.

"너는 밥을 먹었니?"

따라서 한국어에서는 주어가 생략되어도 문맥상 의미가 통하면 문장이 될 수 있다.
```

| 수정 필요성 | 필요 |
| 최종 판단 | 주어 생략 가능성을 설명해야 함 |

# 16. 환각 방지 규칙

나라 강사는 환각을 줄이기 위해 다음 규칙을 따른다.

1. “항상”, “무조건”, “절대” 같은 표현을 함부로 쓰지 않는다.
2. 문법 개념은 예문과 함께 설명한다.
3. 조사만 보고 문장 성분을 판단하지 않는다.
4. 문장 성분은 문장에서 하는 역할을 기준으로 판단한다.
5. 확실하지 않은 내용은 단정하지 않는다.
6. 중학교 문법 범위를 벗어나는 내용은 간단히만 설명한다.
7. 학생이 헷갈릴 수 있는 예외는 짧게 덧붙인다.

```text
- 무엇을? → 편지를

- 목적어:
- 서술어:
```

이를 통해 학생이 왜 틀렸는지 이해하고 다시 풀 수 있도록 하였다.

## 4. 재도전 및 정답 확인 단계

Turn 5에서 학생은 새 문제를 정확히 풀었다.  
AI 튜터는 정답 여부를 알려 주고, 왜 맞았는지 간단히 설명하였다.

|---|---|---|

| 보어 | 서술어의 의미를 완성 | 학생이 되었다 |

## 6. 보어 오답 피드백 단계

Turn 7에서 학생은 “의사가”를 목적어라고 잘못 판단하였다.  
AI 튜터는 이를 오답으로 판단하고, 반드시 오답 해설을 제공하였다.

오답 원인은 다음과 같다.

- ‘의사가’는 동작의 대상이 아니다.

- 따라서 목적어가 아니라 보어이다.

이 피드백은 Few-shot 예시에서 설정한 오답 피드백 규칙을 따른 것이다.

## 7. 조사 기준 오류 교정 단계

첫 번째 문장의 ‘학생이’는 주어이고, 두 번째 문장의 ‘학생이’는 보어이다.  
이를 통해 같은 형태라도 문장에서 맡은 역할에 따라 문장 성분이 달라진다는 점을 설명하였다.

| 영문 | 한글 |
|---|---|
| OBJECT (Mok-jeok-eo) | **목적어** |
| Ask: "WHAT (does the action affect)?" | 질문: "무엇을?" |

### 카드 4 (파란색)
| 영문 | 한글 |
|---|---|
| COMPLEMENT (Bo-eo) | **보어** |

# 인포그래픽 생성 코드

```python
import matplotlib.pyplot as plt
import matplotlib.patches as patches
from matplotlib.patches import FancyBboxPatch

# ============================================
# 1. 캔버스 설정
# ============================================
fig, ax = plt.subplots(figsize=(12, 16))   # 세로형 포스터 비율
ax.set_xlim(0, 12)
ax.set_ylim(0, 16)
ax.axis('off')                              # 좌표축 숨기기
fig.patch.set_facecolor('#FDF6EC')          # 전체 배경: 크림색
ax.set_facecolor('#FDF6EC')

# ============================================
# 2. 색상 팔레트 (파스텔 톤)
# ============================================
colors = {
    'subject':    '#F8BBD0',   # 주어: 분홍
    'predicate':  '#FFCC80',   # 서술어: 주황
    'object':     '#C5E1A5',   # 목적어: 초록
    'complement': '#90CAF9',   # 보어: 파랑
    'warning':    '#FFF59D',   # 주의점: 노랑
    'title_bg':   '#5C6BC0',   # 제목 배경: 남색
}

# ============================================
# 3. 둥근 사각형 카드를 그리는 함수
# ============================================
def draw_card(x, y, w, h, color, title, question, desc, example):
    """
    x, y   : 카드 왼쪽 아래 좌표
    w, h   : 카드 너비, 높이
    color  : 카드 배경색
    title  : 문장 성분 이름 (예: SUBJECT)
    question: 판단 질문 (예: WHO? WHAT?)
    desc   : 개념 설명
    example: 예문
    """
    # 둥근 모서리 카드 배경
    card = FancyBboxPatch(
        (x, y), w, h,
        boxstyle="round,pad=0.1,rounding_size=0.25",
        facecolor=color, edgecolor='#555555', linewidth=2
    )
    ax.add_patch(card)

    cx = x + w / 2   # 카드 가로 중앙

    # 성분 이름 (굵은 제목)
    ax.text(cx, y + h - 0.55, title,
            ha='center', va='center',
            fontsize=17, fontweight='bold', color='#333333')

    # 판단 질문 (흰 배지 형태)
    badge = FancyBboxPatch(
        (cx - 1.9, y + h - 1.45), 3.8, 0.6,
        boxstyle="round,pad=0.05,rounding_size=0.2",
        facecolor='white', edgecolor='#888888', linewidth=1
    )
    ax.add_patch(badge)
    ax.text(cx, y + h - 1.15, question,
            ha='center', va='center',
            fontsize=12, fontweight='bold', color='#D32F2F')

    # 개념 설명
    ax.text(cx, y + h - 2.1, desc,
            ha='center', va='center',
            fontsize=10.5, color='#444444', wrap=True)

    # 예문 (아래쪽, 이탤릭)
    ax.text(cx, y + 0.55, example,
            ha='center', va='center',
            fontsize=10, style='italic', color='#1A237E')

# ============================================
# 4. 제목 영역
# ============================================
title_box = FancyBboxPatch(
    (1, 13.8), 10, 1.7,
    boxstyle="round,pad=0.1,rounding_size=0.3",
    facecolor=colors['title_bg'], edgecolor='none'
)
ax.add_patch(title_box)

ax.text(6, 15.05, 'Korean Grammar for 9th Grade',
        ha='center', va='center',
        fontsize=13, color='#C5CAE9')
ax.text(6, 14.45, 'Sentence Components Made Easy!',
        ha='center', va='center',
        fontsize=22, fontweight='bold', color='white')

# ============================================
# 5. 카드 4장 (2 x 2 배치)
# ============================================
card_w, card_h = 4.8, 4.2

# 카드 1: 주어 (왼쪽 위)
draw_card(0.8, 9.0, card_w, card_h, colors['subject'],
          'SUBJECT (Ju-eo)',
          'Ask: "WHO? / WHAT?"',
          'The doer of the action\nor owner of the state',
          '"Minsu-ga ut-eot-da."\n→ Minsu-ga = SUBJECT')

# 카드 2: 서술어 (오른쪽 위)
draw_card(6.4, 9.0, card_w, card_h, colors['predicate'],
          'PREDICATE (Seo-sul-eo)',
          'Ask: "DOES WHAT? / IS HOW?"',
          'Explains the action or\nstate of the subject',
          '"Minsu-ga ut-eot-da."\n→ ut-eot-da = PREDICATE')

# 카드 3: 목적어 (왼쪽 아래)
draw_card(0.8, 4.2, card_w, card_h, colors['object'],
          'OBJECT (Mok-jeok-eo)',
          'Ask: "WHAT?"',
          'The target of the action',
          '"Minsu-ga chaek-eul ilg-eot-da."\n→ chaek-eul = OBJECT')

# 카드 4: 보어 (오른쪽 아래)
draw_card(6.4, 4.2, card_w, card_h, colors['complement'],
          'COMPLEMENT (Bo-eo)',
          'Ask: "BECOMES? / IS NOT?"',
          "Completes the meaning of\n'doeda' & 'anida'",
          '"Na-neun haksaeng-i doe-eot-da."\n→ haksaeng-i = COMPLEMENT')

# ============================================
# 6. 핵심 주의점 박스 (하단)
# ============================================
warn_box = FancyBboxPatch(
    (0.8, 0.8), 10.4, 2.8,
    boxstyle="round,pad=0.1,rounding_size=0.3",
    facecolor=colors['warning'], edgecolor='#F9A825', linewidth=3
)
ax.add_patch(warn_box)

ax.text(6, 3.1, '⚠ KEY POINT!',
        ha='center', va='center',
        fontsize=16, fontweight='bold', color='#E65100')

ax.text(6, 2.3,
        "Don't judge by the particle (jo-sa) alone —\n"
        "look at the ROLE the word plays in the sentence!",
        ha='center', va='center',
        fontsize=12.5, fontweight='bold', color='#333333')

ax.text(6, 1.3,
        '"haksaeng-i" can be a SUBJECT or a COMPLEMENT — the role decides!',
        ha='center', va='center',
        fontsize=10.5, style='italic', color='#555555')

# ============================================
# 7. 저장
# ============================================
plt.tight_layout()
plt.savefig('sentence_components_infographic.png',
            dpi=150,                     # 해상도
            bbox_inches='tight',
            facecolor='#FDF6EC')         # 저장 시 배경색 유지
plt.show()
```

3. **좌표 배치**: `xlim(0,12)`, `ylim(0,16)` 좌표계 안에서 제목(위) → 카드 2×2(중간) → 주의점(아래) 순으로 배치했습니다.

# 인포그래픽 생성 코드

```python
import matplotlib.pyplot as plt
import matplotlib.patches as patches
from matplotlib.patches import FancyBboxPatch

# ============================================
# 1. 캔버스 설정
# ============================================
fig, ax = plt.subplots(figsize=(12, 16))   # 세로형 포스터 비율
ax.set_xlim(0, 12)
ax.set_ylim(0, 16)
ax.axis('off')                              # 좌표축 숨기기
fig.patch.set_facecolor('#FDF6EC')          # 전체 배경: 크림색
ax.set_facecolor('#FDF6EC')

# ============================================
# 2. 색상 팔레트 (파스텔 톤)
# ============================================
colors = {
    'subject':    '#F8BBD0',   # 주어: 분홍
    'predicate':  '#FFCC80',   # 서술어: 주황
    'object':     '#C5E1A5',   # 목적어: 초록
    'complement': '#90CAF9',   # 보어: 파랑
    'warning':    '#FFF59D',   # 주의점: 노랑
    'title_bg':   '#5C6BC0',   # 제목 배경: 남색
}

# ============================================
# 3. 둥근 사각형 카드를 그리는 함수
# ============================================
def draw_card(x, y, w, h, color, title, question, desc, example):
    """
    x, y   : 카드 왼쪽 아래 좌표
    w, h   : 카드 너비, 높이
    color  : 카드 배경색
    title  : 문장 성분 이름 (예: SUBJECT)
    question: 판단 질문 (예: WHO? WHAT?)
    desc   : 개념 설명
    example: 예문
    """
    # 둥근 모서리 카드 배경
    card = FancyBboxPatch(
        (x, y), w, h,
        boxstyle="round,pad=0.1,rounding_size=0.25",
        facecolor=color, edgecolor='#555555', linewidth=2
    )
    ax.add_patch(card)

    cx = x + w / 2   # 카드 가로 중앙

    # 성분 이름 (굵은 제목)
    ax.text(cx, y + h - 0.55, title,
            ha='center', va='center',
            fontsize=17, fontweight='bold', color='#333333')

    # 판단 질문 (흰 배지 형태)
    badge = FancyBboxPatch(
        (cx - 1.9, y + h - 1.45), 3.8, 0.6,
        boxstyle="round,pad=0.05,rounding_size=0.2",
        facecolor='white', edgecolor='#888888', linewidth=1
    )
    ax.add_patch(badge)
    ax.text(cx, y + h - 1.15, question,
            ha='center', va='center',
            fontsize=12, fontweight='bold', color='#D32F2F')

    # 개념 설명
    ax.text(cx, y + h - 2.1, desc,
            ha='center', va='center',
            fontsize=10.5, color='#444444', wrap=True)

    # 예문 (아래쪽, 이탤릭)
    ax.text(cx, y + 0.55, example,
            ha='center', va='center',
            fontsize=10, style='italic', color='#1A237E')

# ============================================
# 4. 제목 영역
# ============================================
title_box = FancyBboxPatch(
    (1, 13.8), 10, 1.7,
    boxstyle="round,pad=0.1,rounding_size=0.3",
    facecolor=colors['title_bg'], edgecolor='none'
)
ax.add_patch(title_box)

ax.text(6, 15.05, 'Korean Grammar for 9th Grade',
        ha='center', va='center',
        fontsize=13, color='#C5CAE9')
ax.text(6, 14.45, 'Sentence Components Made Easy!',
        ha='center', va='center',
        fontsize=22, fontweight='bold', color='white')

# ============================================
# 5. 카드 4장 (2 x 2 배치)
# ============================================
card_w, card_h = 4.8, 4.2

# 카드 1: 주어 (왼쪽 위)
draw_card(0.8, 9.0, card_w, card_h, colors['subject'],
          'SUBJECT (Ju-eo)',
          'Ask: "WHO? / WHAT?"',
          'The doer of the action\nor owner of the state',
          '"Minsu-ga ut-eot-da."\n→ Minsu-ga = SUBJECT')

# 카드 2: 서술어 (오른쪽 위)
draw_card(6.4, 9.0, card_w, card_h, colors['predicate'],
          'PREDICATE (Seo-sul-eo)',
          'Ask: "DOES WHAT? / IS HOW?"',
          'Explains the action or\nstate of the subject',
          '"Minsu-ga ut-eot-da."\n→ ut-eot-da = PREDICATE')

# 카드 3: 목적어 (왼쪽 아래)
draw_card(0.8, 4.2, card_w, card_h, colors['object'],
          'OBJECT (Mok-jeok-eo)',
          'Ask: "WHAT?"',
          'The target of the action',
          '"Minsu-ga chaek-eul ilg-eot-da."\n→ chaek-eul = OBJECT')

# 카드 4: 보어 (오른쪽 아래)
draw_card(6.4, 4.2, card_w, card_h, colors['complement'],
          'COMPLEMENT (Bo-eo)',
          'Ask: "BECOMES? / IS NOT?"',
          "Completes the meaning of\n'doeda' & 'anida'",
          '"Na-neun haksaeng-i doe-eot-da."\n→ haksaeng-i = COMPLEMENT')

# ============================================
# 6. 핵심 주의점 박스 (하단)
# ============================================
warn_box = FancyBboxPatch(
    (0.8, 0.8), 10.4, 2.8,
    boxstyle="round,pad=0.1,rounding_size=0.3",
    facecolor=colors['warning'], edgecolor='#F9A825', linewidth=3
)
ax.add_patch(warn_box)

ax.text(6, 3.1, '⚠ KEY POINT!',
        ha='center', va='center',
        fontsize=16, fontweight='bold', color='#E65100')

ax.text(6, 2.3,
        "Don't judge by the particle (jo-sa) alone —\n"
        "look at the ROLE the word plays in the sentence!",
        ha='center', va='center',
        fontsize=12.5, fontweight='bold', color='#333333')

ax.text(6, 1.3,
        '"haksaeng-i" can be a SUBJECT or a COMPLEMENT — the role decides!',
        ha='center', va='center',
        fontsize=10.5, style='italic', color='#555555')

# ============================================
# 7. 저장
# ============================================
plt.tight_layout()
plt.savefig('sentence_components_infographic.png',
            dpi=150,                     # 해상도
            bbox_inches='tight',
            facecolor='#FDF6EC')         # 저장 시 배경색 유지
plt.show()
```

# 코드 핵심 구조 설명

| 부분 | 역할 |
|---|---|
| `figsize=(12, 16)` | 세로형 포스터 비율 설정 |
| `colors` 딕셔너리 | 성분별 파스텔 색상을 한곳에서 관리 |
